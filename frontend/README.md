# Precedent Frontend

React frontend dashboard for the Precedent AI Sales Strategist.

## Features
- **Modern Dark Glassmorphism UI**: Built with CSS variable token system (`styles.css`)
- **Real-Time Telemetry**: Live ping latency and connection status indicator
- **API Control Workbench**: Interactive test triggers for `/api/v1/health` and `/api/v1/status`
- **Subsystem & Roadmap Monitors**: Multi-phase tracking dashboard

## Running Locally

```bash
npm run dev
```

The application will be accessible at [http://localhost:5173](http://localhost:5173).
