# Precedent

Persistent-memory AI sales strategist for HackWithHyderabad 3.0.

## Overview
Precedent remembers deal history, learns from interactions, and recommends next best actions using Hindsight memory and Google ADK.

## Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Python, FastAPI
- Agent: Google ADK
- Memory: Hindsight
